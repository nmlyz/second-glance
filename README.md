A tiny program that writes one sentence pitching a bizarre startup idea to
a text file. The line is a single sentence of at most 200 characters: an
idea that sounds absurd at first glance, until the business behind it
lands. It names the odd thing being sold, who pays for it, and why it
holds together.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
